# Workshop2026 — FoodLink

Waste2Wealth AI marketplace for Malaysian SMEs. Businesses list surplus stock, by-products, near-expiry goods, or industrial waste; FoodLink ranks nearby matches and tracks circular-economy impact.

Live demo: https://workshop2026-foodlink.web.app/

## Run locally

```bash
npm install
npm run dev
```

## Firebase

- Project: `workshop2026-foodlink` (display name: `Workshop2026`)
- Firestore stores user-created surplus listings.
- Hosting serves the production Vite build.

Deploy with `npm run build && firebase deploy`.
